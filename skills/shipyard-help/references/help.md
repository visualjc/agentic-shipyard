# Help reference

The public commands are `shipyard`, `shipyard-setup`, `shipyard-status`,
`shipyard-review`, `shipyard-sync`, `shipyard-promote`, `shipyard-finalize`,
and `shipyard-help`. Each has a focused skill and reference. Help does not
load the complete operating model.

Codex CLI is the only supported live v1 host; Claude Code and Cursor/Pstack
are deferred and unsupported. Next safe action: invoke the selected public
command.
