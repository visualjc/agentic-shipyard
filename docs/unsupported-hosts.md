# Deferred hosts

Shipyard v1 supports only Codex CLI `0.144.4`. Claude Code/CCPM and Cursor/Pstack are deliberately deferred. Their presence is reported as incompatible for a requested v1 delivery; no example or status result implies that they can run CCPM planning, select an account, or perform a Shipyard mutation.

Legacy `/pm:*` aliases are migration documentation only. Shipyard neither installs aliases nor guesses compatibility behavior.
