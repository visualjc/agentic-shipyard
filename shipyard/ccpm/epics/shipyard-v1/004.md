# Task: Deliver safe baseline and source-ref synchronization

## Description

Implement explicit synchronization without turning it into promotion or branch
repair: fast-forward a clean development baseline from its authoritative
destination and optionally import one named destination ref as a local
read-only source object.

## Acceptance Criteria

- [ ] Default sync requires clean, non-divergent baselines and fast-forwards
  development `main` to exactly destination `main`.
- [ ] Dirty state, divergence, unexpected remote identity, or a non-fast-forward
  update blocks without rebasing or conflict resolution.
- [ ] The shared one-owner path classifier blocks sync when relevant changed
  paths are unclassified or conflicting.
- [ ] A named branch/tag/ref is imported only after explicit input into
  `refs/shipyard/source/...` with recorded remote/name/SHA provenance.
- [ ] Source refs are excluded from Shipyard push refspecs and provenance/SHA
  changes are detected before use.
- [ ] Sync never promotes, finalizes, force-pushes, or rewrites feature work.
- [ ] Evidence covers PRD AC-005 and AC-006.

## Technical Details

- Treat source-ref immutability as verified policy, not a Git-native guarantee.
- Use the GitHub/Git credential boundary from task 003.
- Keep status read-only and make every stop condition explain the safe next step.
- Acquire the shared mutation lock and contribute baseline/source provenance,
  freshness, blockers, and next action to status.

## Dependencies

- Depends on task 001 binding and task 003 scoped provider/Git transport.

## Effort Estimate

- Size: M
- Hours: 20–28

## Definition of Done

- [ ] Code implemented as a narrow `shipyard-sync` operation.
- [ ] Local staged-pair integration and negative-divergence tests pass.
- [ ] Sync/source-ref documentation is complete.
- [ ] Acceptance evidence names the exact product SHA and verifier.
- [ ] Independent code review has no unresolved accepted finding.
