# Task: Deliver exact-SHA acceptance and Codex review

## Description

Close the evidence gap left by ordinary CCPM task completion: validate every
acceptance and Definition of Done item against one exact product SHA, then run
an independent ephemeral Codex review whose findings and resolution are durable
ledger records.

## Acceptance Criteria

- [ ] Acceptance and Definition of Done records enforce stable IDs, state,
  exact product SHA, evidence reference, verifier, and verification time.
- [ ] Any product-SHA change makes prior acceptance/review evidence stale and
  blocks promotion until renewed.
- [ ] Codex review runs in a separate ephemeral process/session from the
  implementer and receives the reviewer envelope only.
- [ ] Accepted findings remain blocking until a resolution and renewed review
  name the current SHA.
- [ ] Checked task boxes, raw CCPM completion, and GitHub approval state cannot
  substitute for Shipyard evidence.
- [ ] Evidence covers PRD AC-014 and AC-015.

## Technical Details

- Define machine-validated evidence schemas and a pure freshness evaluator.
- Persist review prompts/results and finding disposition to the ledger.
- Keep the adapter interface host-neutral while supporting Codex only in v1.
- Contribute acceptance/review freshness, blocking findings, provider
  presentation state, and next action to the shared status projection.

## Dependencies

- Depends on task 002 ledger/context and task 003 development tracking.

## Effort Estimate

- Size: L
- Hours: 28–36

## Definition of Done

- [ ] Code implemented with deterministic validation output.
- [ ] Unit, stale-SHA, role-isolation, and independent-process tests pass.
- [ ] Acceptance/review documentation is complete.
- [ ] This task's own acceptance evidence names its exact product SHA.
- [ ] Independent code review has no unresolved accepted finding.
