# Task: Deliver single-repository certification and finalization

## Description

Deliver the AI-native/single-repository path: certify one existing PR at its
accepted and independently reviewed SHA, publish the dossier, observe human
merge, and archive evidence without creating a redundant destination PR.

## Acceptance Criteria

- [ ] Certification verifies the existing PR belongs to the bound repository
  and its head exactly matches fresh acceptance/review evidence.
- [ ] Prohibited metadata or an unclassified path blocks readiness.
- [ ] Shipyard attaches/updates the review dossier idempotently and does not
  create a second PR.
- [ ] Shipyard never merges the PR; finalization begins only after the expected
  human/team merge is observed.
- [ ] Final ledger/tag/archive and branch cleanup are resumable and consistent
  with single-repository ownership.
- [ ] Path ownership and prohibited-metadata policy are revalidated before
  certification and finalization.
- [ ] Dedicated local and private synthetic acceptance coverage proves this
  topology before release.
- [ ] Evidence covers PRD AC-016 and AC-018.
