# Task: Add experimental graph freshness adapters

## Description

Implement the optional, explicitly experimental graph lane without weakening
source correctness: exact-main baselines may seed isolated per-worktree
Graphify or CodeGraph caches, and every session must prove freshness or fall
back to direct source inspection.

## Acceptance Criteria

- [x] The core graph contract keys authority by exact commit and working-tree
  fingerprint and never shares mutable state across divergent worktrees.
- [x] Graphify output is fully relocated and verified after seed/incremental
  refresh.
- [x] CodeGraph verifies its Node/FTS5 runtime, keeps `.codegraph/` excluded, and
  labels cache seeding as empirical rather than upstream-guaranteed.
- [x] Commit, dirty edit, checkout, rebase, process restart, worktree recreation,
  stale lock, and unavailable-tool states are detected.
- [x] Stale/failed/unavailable graphs fall back to direct source inspection.
- [x] Understand Anything is not exposed as authoritative feature-worktree state.
- [x] Evidence covers PRD AC-022.

## Technical Details

- Reuse the synthetic fixtures and reviewed adapter pins from Wayfinder.
- Keep adapter flags explicit and disabled by default.
- Do not send proprietary code to an unapproved provider.
- Contribute adapter enabled/fresh/stale/unavailable state and fallback action
  to the shared status projection.
