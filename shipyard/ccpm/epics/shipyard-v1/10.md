# Task: Add experimental graph freshness adapters

## Description

Implement the optional, explicitly experimental graph lane without weakening
source correctness: exact-main baselines may seed isolated per-worktree
Graphify or CodeGraph caches, and every session must prove freshness or fall
back to direct source inspection.

## Acceptance Criteria

- [ ] The core graph contract keys authority by exact commit and working-tree
  fingerprint and never shares mutable state across divergent worktrees.
- [ ] Graphify output is fully relocated and verified after seed/incremental
  refresh.
- [ ] CodeGraph verifies its Node/FTS5 runtime, keeps `.codegraph/` excluded, and
  labels cache seeding as empirical rather than upstream-guaranteed.
- [ ] Commit, dirty edit, checkout, rebase, process restart, worktree recreation,
  stale lock, and unavailable-tool states are detected.
- [ ] Stale/failed/unavailable graphs fall back to direct source inspection.
- [ ] Understand Anything is not exposed as authoritative feature-worktree state.
- [ ] Evidence covers PRD AC-022.

## Technical Details

- Reuse the synthetic fixtures and reviewed adapter pins from Wayfinder.
- Keep adapter flags explicit and disabled by default.
- Do not send proprietary code to an unapproved provider.
- Contribute adapter enabled/fresh/stale/unavailable state and fallback action
  to the shared status projection.

## Dependencies

- Depends on task 001 core policy and task 002 worktree/ledger context.

- Size: M

## Definition of Done

- [ ] Experimental adapters and safe fallback are implemented.
- [ ] Exact-source freshness and process-restart tests pass.
- [ ] Experimental/privacy/runtime documentation is complete.
- [ ] Acceptance evidence names the exact product SHA and verifier.
- [ ] Independent code review has no unresolved accepted finding.
