# Large development

1. Apply the [run start contract](../references/run-start.md) and verify that unresolved product or architecture decisions justify `large-development`.
2. Invoke `wayfinder` to produce the decision map, decision tickets, fog, and frontier. Do not turn decision tickets directly into build work.
3. Use read-only `research` autonomously for factual unknowns. Use `prototype` for empirical design questions and stop for human feedback before adopting its result.
4. When decision fog is resolved, invoke `to-spec`, then `to-tickets`. Index canonical artifacts and blocker edges.
5. Select `matt` or the explicitly configured pstack enhancement. Work the executable frontier with complete briefs and immutable events.
6. Create or update the agentic PR through [agentic-pr.md](agentic-pr.md), run the integrated [exact-SHA delivery gate](../references/delivery-gate.md), promote reviewed cargo, and monitor the delivery PR through the feedback loop and human merge.

Output the decision frontier, canonical spec/tickets, build provider, verified head, delivery state, and one next action.
